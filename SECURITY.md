## Reporting a Vulnerability

Se você encontrou uma vulnerabilidade de segurança no **LogicBan**, siga os passos abaixo para reportá-la de maneira responsável:

1. **Não divulgue publicamente:** Evite compartilhar detalhes da vulnerabilidade em fóruns, redes sociais ou outros canais públicos antes de uma correção ser disponibilizada.
2. **Envie um e-mail para** [seu-email@exemplo.com] **com o título** `Security Issue: [breve descrição]`.
3. **Forneça detalhes técnicos**, incluindo:
   - Versão do software afetada
   - Passos para reproduzir o problema
   - Impacto potencial da vulnerabilidade
   - Qualquer solução temporária sugerida
4. **Nosso compromisso:**
   - Responderemos ao seu relatório dentro de **[X dias]**.
   - Se confirmada, trabalharemos para corrigir o problema e lançaremos uma atualização de segurança.
   - Daremos crédito a você no changelog, caso deseje.

Agradecemos sua colaboração em manter o **LogicBan** seguro para todos! 🚀
