# Contribuindo para o LogicBan

Obrigado por considerar contribuir para o **LogicBan**! Este documento fornece as diretrizes para contribuir com o projeto.

## Como Contribuir

Existem várias maneiras de contribuir para o **LogicBan**:

### 1. Reportando um Problema

Se você encontrou um erro ou tem uma sugestão de melhoria, por favor, siga estas etapas:

- Verifique se o problema já foi reportado ou se a sugestão já foi feita. Use a busca para evitar duplicações.
- Abra uma **issue** descrevendo o problema ou a sugestão, com o máximo de detalhes possível, incluindo:
  - Versão do jogo (se aplicável)
  - Sistema operacional utilizado
  - Passos para reproduzir o problema
  - Capturas de tela ou logs (se necessário)

### 2. Enviando um Pull Request

Caso queira contribuir com código, siga esses passos:

1. **Fork o repositório**: Crie uma cópia do repositório no seu GitHub.
2. **Clone o seu fork**:
   
   ```bash
   git clone https://github.com/seu-usuario/logicban.git
   cd logicban
   ```
   
3. **Crie uma branch para a sua modificação**:
   ```bash
   git checkout -b minha-nova-funcionalidade
   ```
   
4. Faça suas modificações.

5. Commit as mudanças:

   ```bash
   git add .
   git commit -m "Descrição clara das alterações"
   ```

6. **Suba suas mudanças para o seu fork**:
   
   ```bash
   git push origin minha-nova-funcionalidade
   ```

8. Abra um Pull Request para o repositório original, explicando as mudanças feitas.

### 3. Testando o Jogo
Para garantir que o jogo funcione corretamente após as modificações, siga os seguintes passos:

- Instale as dependências do projeto.
- Execute o jogo localmente e teste as funcionalidades que você alterou ou adicionou.
- Se você encontrar bugs durante o processo, reporte-os na seção de Issues.

### 4. Traduções
Se você quer ajudar a traduzir o jogo ou melhorar a documentação, basta procurar pelas strings no código ou na documentação. Para sugestões de traduções, você pode adicionar as mudanças no arquivo de tradução correspondente e enviar um pull request.

Código de Conduta
Ao contribuir para o LogicBan, esperamos que todos sigam nosso [Código de Conduta](https://github.com/GustavoBorges13/LogicBan/edit/main/CODE_OF_CONDUCT.md). O respeito mútuo e o comportamento profissional são fundamentais para o bom andamento da comunidade.

Licença

Se você tiver alguma dúvida, não hesite em abrir uma issue ou entrar em contato!

Obrigado pela sua contribuição para o LogicBan! """
